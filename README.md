# B2B 短视频脚本编导

一个用于海外 B2B 社媒视频的 Codex skill：参考成稿特点，先比较不同方向，再展开选中的版本，最后简化英文。

适合采购科普、产品销售、工厂日常、实测、客户案例及已拍素材配音。默认中文讨论，英文完整脚本后附中文。可以直接请求成稿，也可以只改局部。

## 使用

把此仓库作为 skill 安装，文件夹名称为 `b2b-short-video-director`。安装后在新会话中说：

> 用 $b2b-short-video-director 处理以下素材。先给我 10 个不同的短方向，我选出喜欢的，再展开。

或：

> 用 $b2b-short-video-director 自行选择最合适的方向，直接给我英文和中文成稿。

提供目标客户、可用素材、产品事实及希望客户采取的行动即可。缺关键资料时 skill 会提出少量选项式问题；不用先填写完整表格。

## 资料说明

公开包仅含通用方法与匿名教学示例，不包含特定企业的品牌配置、客户联系方式、内部资料或凭证。示例中的产品功能和服务不是可照搬的业务承诺。实际品牌信息在各自任务中提供，不自动写入公开仓库。

这里的检查用于帮助创作，不保证视频成为爆款或取得销售结果。方法来源在相应参考文件中列出。
