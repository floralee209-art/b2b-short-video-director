# 选材、销售路径与表现

按当前决定读对应小节。这里是可组合的工具，不是每条都要填写的表格。

## 根据观看价值选类型

| 类型 | 观众为什么看 | 本条优先完成什么 |
| --- | --- | --- |
| 采购科普 | 有问题，想知道怎么办 | 给一个好用的判断或动作，再承接品牌能提供的帮助 |
| 产品/服务销售 | 想知道是否适合、是否可信 | 回答主要顾虑，展示对应产品或服务证据 |
| 超短投流广告 | 快速判断是否与自己有关 | 人群/目标、主要优势、必要证明、一个行动；不强行补完整故事 |
| 工厂日常 | 想看真实生产、测试或处理 | 可见动作、关键细节、与买方有关的意义；可以无真人口播 |
| 实测演示 | 想看差异和实际结果 | 条件可比、结果可观察、结论不超过测试范围 |
| 客户案例 | 想看类似客户如何选择和落地 | 真实处境、选择理由、已证实的变化、相关下一步 |
| 本地渠道/批发 | 想看进货、利润空间、供货与取货 | 当前真实价格、适合谁、如何销售与补货、实际可用渠道 |

类别可以扩展。同一画面可服务不同任务；选素材最能支撑、买方最愿意看的用途。不要把一次“经营建议比问答更好”的反馈推广到所有视频。

## 选择一条主导说服路径

| 当前购买障碍 | 可借用的销售方法 | 视频中的推进 |
| --- | --- | --- |
| 意识到麻烦，却不清楚改善价值 | SPIN 或 Gap Selling | 具体处境 → 问题的实际影响 → 有依据的改善价值 |
| 目标明确，不知怎样落地 | Solution Selling | 目标与约束 → 合适方案 → 品牌完成哪部分 |
| 比来比去，不会判断 | Challenger 或 Sense Making | 原比较办法的遗漏 → 可操作的新判断 → 证据与建议 |
| 想买，但担心选错 | JOLT | 找到真正犹豫 → 给有理由的建议 → 可兑现的风险应对 |
| 卡在选型、运输等采购任务 | Buyer Enablement | 当前任务 → 一步可执行的办法 → 必要支持 |

这些是对方法的创作应用，不是原作者规定的短视频模板。科普和日常可只借其中一个判断，不需要完整展开。各版本可以换路径，不把几套方法的步骤串成一条视频。

“营销最后一天的人”是一种受众选择：临近采购的人更需要比较依据和保障；比价本身不证明他马上会下单。早期客户仍可能需要知识和方案。

有复杂采购背景才借用：Sandler（确认需求和约束）；Miller Heiman（多方决策）；MEDDPICC、SPICED（采购缺口及关键事件）。JTBD 用于理解客户要取得的进展；影响力原则用于选择真实信任证据。Sprint Selling、Activator 可启发后续推进与关系经营，不强制变成视频结构。不向观众盘问整套资格字段。

## 注意力和活人感

选择与内容适配的手法：

- 直接点名角色与眼前决定；用观众的具体处境代替“大多数人都担心质量”。
- 从一个可观察的动作、结果或差异开始；口播补上画面本身说不清的意义。
- 提出一个值得追下去的问题，正文及时回答，不靠拖延答案制造悬念。
- 反问、惊讶、停顿、轻微吐槽可以用，但要有对象和原因；不强加口头禅。
- 对话里的不同意见用于推进判断；镜头可转向设备、操作或结果，不每句都面向观众。
- 多段之间用具体承接维持节奏，不要求每几秒跳切、反转或加音效。

口播、对话、演示和旁白均可。表演的情境可以设计，但不得冒充真实客户见证。动作提示只写关键处；未经用户要求，不扩展成拍摄日程或完整制作手册。

## 已拍视频与长度

先确认素材可重剪还是成片锁定。可重剪时选最有价值的画面定长度；锁定时按实际配音窗口删减信息。一个工序只有一个好细节，就围绕它写短稿，不填满原素材。

看到视频后才描述实际动作；仅有文字描述时注明依据。只看抽帧不能声称验证了连续动作或声音。未知源时间码不编造，用镜头顺序。

有必要时估算：英文词数 ≈ 可配音秒数 × 采用的每分钟词数 ÷ 60。优先实际试读速度，没有样本就写明规划假设。时长和配音不参与文案质量打分，也不保证估算即实录时长。需要交付剪辑稿时，附最简“画面—对应台词—必要字幕/原声”表。

## 方法来源

保留方法归属，按需核查原文；不要求安装第三方 skill，也不默认访问所有链接。

- 销售：[SPIN](https://www.huthwaiteinternational.com/spin-methodology)、[Challenger](https://challengerinc.com/what-is-challenger-sales-methodology/)、[JOLT](https://www.jolteffect.com/curriculum)、[Solution Selling](https://www.richardson.com/sales-training-programs/sales-professionals/solution-selling/)、[MEDDPICC](https://meddicc.com/meddpicc-sales-methodology-and-process)、[SPICED](https://winningbydesign.com/spiced-framework/)。
- 口播与日常：[social-media-skills](https://github.com/social-media-skills/skills)。借用说话对象、实际操作、理解意思再录制等原则。
- 视觉开头：[PostPlusAI / hook-skills](https://github.com/PostPlusAI/hook-skills)。借用首镜头与证据的关系，不继承强制模板或推广要求。
- 内容节奏：[vyralcontent / content-skills](https://github.com/vyralcontent/content-skills)。借用具体表达与承诺兑现，不把经验当算法规则。
